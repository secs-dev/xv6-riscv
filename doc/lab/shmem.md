# Задание. Shared Memory

## Введение

Сейчас в `Xv6` процессы могут обмениваться данными
только через pipes, что требует копирования через
ядро и не годится для больших объёмов или двунаправленной
коммуникации. Shared memory отображает одну физическую
область в адресные пространства нескольких процессов —
самый быстрый IPC в промышленных ОС.

## Задача

Добавьте в Xv6 возможность коммуникации между
процессами при помощи shared memory.

Изучите API данной функциональности в других ОС,
после чего спроектируйте и разработайте свой.

Реализуйте буфферизованный канал в Xv6 и
producer-consumer приложение.
