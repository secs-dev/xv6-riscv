# Задание. MLFQ

## Введение

Сейчас `Xv6` планирует процессы по принципу round-robin:
все равны, интерактивные и CPU-bound процессы ждут одинаково.
MLFQ (multi-level feedback queue) адаптирует приоритет
по поведению процесса и улучшает отклик интерактивных задач.

## Задача

Замените политику планирования процессов
в Xv6 с round-robin на MLFQ.
