# Задание. Backtrace

В ядре ОС реализуйте процедуры для получения backtrace
со стеков как в userspace, так и kernelspace.

Сам backtrace представляет собой список/массив адресов.

Рекомендуется выразить backtrace в виде отдельной
программной сущности.

Также реализуйте и продемонстрируйте работу процедуры по
печати backtrace в терминал.

Реализуйте скрипт для преобразования списка адресов
в понятное человеку текстовое представление функций
(symbolize an address).
