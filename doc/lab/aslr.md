# Задание. ASLR

## Введение

Сейчас `Xv6` загружает каждый процесс по фиксированному
адресу, поэтому смещения кода и данных известны заранее.
Это делает возможными атаки на переполнение буфера с
возвратом по фиксированным адресам (`return-to-libc`,
ROP-цепочки), где эксплойт использует заранее известные
расположения libc и функций. ASLR (рандомизация раскладки
адресного пространства) лишает атакующего этих констант и
 применяется во всех современных ОС.

## Задача

Реализуйте ASLR в Xv6.
