# Задание. Аллокатор RAM для структур процессов

## Введение

Сейчас структуры процессов в `Xv6` хранятся в
статическом массиве фиксированного размера — `NPROC`
процессов. Это сильно ограничивает конкурентность.
Динамическое выделение памяти через buddy-аллокатор
устраняет это.

## Задача

Примените `buddy allocator` для структур процессов,
аналогично части 1. Тесты на эту часть отсутствуют,
оно проверяется преподавателем вручную. Не забудьте
проверить, что usertests работают.
