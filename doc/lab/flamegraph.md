# Задание. FlameGraph

Вы уже реализовали получение backtrace по стеку.
Теперь вам предлагается разработать свой простой
сэмплирующий профилировщик в Xv6.

Идея следующая. Периодически (при помощи таймера)
снимать текущий backtrace процесса и записывать
его в отображение backtrace -> frequency. Таким
образом получится построить распределение backtraces
по частоте.

Добавьте системные вызовы для управления
профилированием: начало, остановка, получение
результатов.

Разработайте скрипт для преобразования результатов
профилирования во FlameGraph.
